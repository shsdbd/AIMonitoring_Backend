# 🎬 YOLOv8 동물 탐지 프로젝트 - 코드 분석

## 전체 플로우

```
AIHub 동물 데이터 (JSON + JPG)
    ↓
[main.py] YOLOv8 데이터셋 변환 및 학습
    ↓
[test.py] 학습된 모델로 추론 및 검출 기록
```

---

## 1️⃣ main.py - 데이터 파이프라인 & 모델 학습

### 📥 입력

- **라벨 데이터**: AIHub JSON 형식 → `[[x_min, y_min], [x_max, y_max]]` 바운딩박스
- **이미지**: JPG 파일들 (1920×1080 해상도)
- **구조**: 
  ```
  01. 데이터/
  ├─ 1.Training/라벨링데이터/TL_01.고라니, TL_02.멧돼지, TL_03.너구리
  ├─ 1.Training/원천데이터/TS_01.고라니, TS_02.멧돼지, TS_03.너구리
  ├─ 2.Validation/라벨링데이터/VL_01~03
  └─ 2.Validation/원천데이터/VS_01~03
  ```

### 🔄 핵심 변환

| 단계 | 작업 | 출력 |
|------|------|------|
| **1. JSON 파싱** | AIHub JSON에서 이미지 정보 + 바운딩박스 추출 | 동물 종 + 좌표 |
| **2. 좌표 변환** | `[[x_min, y_min], [x_max, y_max]]` → 정규화된 `[x_center, y_center, w, h]` | YOLO 형식 좌표 |
| **3. 라벨 파일 생성** | 각 이미지마다 `.txt` 파일 작성 (1 이미지 = 1 텍스트 파일) | `class_id x_center y_center width height` |
| **4. 데이터 분할** | 80% 훈련 / 20% 검증 (자동 섞임) | Train: 67,275장 / Val: 16,820장 |
| **5. data.yaml 생성** | YOLO 설정 파일 (경로, 클래스 정보) | `path, train, val, nc, names` |

### 🎓 학습 설정

```python
Model: YOLOv8n (나노 모델 - 경량)
Epochs: 50
Batch Size: 16
Image Size: 640×640
Learning Rate: 자동 (권장값)
Workers: 4
Patience: 10 (조기 종료)
```

### 📤 출력

```
01. 데이터/yolo_animals/
├─ images/
│   ├─ train/  (67,275개 JPG)
│   └─ val/    (16,820개 JPG)
├─ labels/
│   ├─ train/  (67,275개 TXT)
│   └─ val/    (16,820개 TXT)
└─ data.yaml

runs/animal_detector_yolov8n/
├─ weights/best.pt  ⭐ 최적 모델
├─ weights/last.pt  (마지막 에포크)
└─ [훈련 로그, 그래프 등]
```

### 🔍 특수 처리

- **인코딩**: UTF-8 → CP949로 폴백 (한글 처리)
- **OpenMP 충돌**: `KMP_DUPLICATE_LIB_OK=TRUE` 설정
- **중복 라벨 제거**: 같은 좌표의 중복 객체 자동 정리
- **무시 규칙**: 알 수 없는 종 또는 좌표 없는 라벨 건너뜀

## 2️⃣ test.py - 추론 & 검출 기록

### 📥 입력

```python
Model: best.pt (훈련된 가중치)
이미지: 테스트 이미지 폴더 또는 단일 파일
신뢰도 임계값: 0.4 (40% 이상만 탐지)
```

### 🔍 추론 과정

```
테스트 이미지
    ↓
[best.pt 로드] YOLOv8n 모델 로드
    ↓
[추론 실행] 이미지 통과 → bounding boxes + confidence 획득
    ↓
[필터링] confidence ≥ 0.4인 객체만 유지
    ↓
[좌표 변환] YOLO [xyxy] → 정규화된 [x, y, w, h] 변환
    ↓
[메타데이터 생성] JSON 기록 (이미지명, 종, 신뢰도, 좌표, 타임스탬프)
    ↓
[저장] detected_events.json
```

### 📤 출력 파일 구조

```json
{
  "detection_results": [
    {
      "image_file": "A01_H69_C009_C_211106_3012_20S_000006.726.jpg",
      "detected_objects": [
        {
          "objectType": "detection",
          "species": "gorani",
          "confidence": 0.92,
          "bbox_normalized": {
            "x": 0.35,
            "y": 0.42,
            "width": 0.18,
            "height": 0.21
          }
        }
      ],
      "timestamp": "2026-05-26T14:30:45.123456+00:00",
      "image_dimensions": {"width": 1920, "height": 1080}
    }
  ]
}
```

### 🎯 클래스 매핑

```python
0 → gorani      (고라니)
1 → wild_boar   (멧돼지)
2 → raccoon     (너구리)
```

## 3️⃣ 전체 논리 요약

### ✅ 목표

한국의 야생동물(고라니, 멧돼지, 너구리) 감시 카메라 영상에서 동물을 AI로 자동 탐지

### 📊 데이터 흐름

```
원본 (84K 이미지)
  ↓ [JSON 파싱 + 좌표 변환]
YOLO 형식 데이터셋 (84K)
  ↓ [YOLOv8n 학습]
훈련된 모델 (best.pt)
  ↓ [test 이미지 추론]
검출 결과 JSON (위치, 신뢰도, 종)
```

### 🔧 핵심 함수들

| 함수명 | 역할 |
|--------|------|
| `build_yolo_dataset()` | 전체 파이프라인 오케스트레이션 |
| `parse_aihub_json()` | AIHub JSON 파싱 |
| `convert_bbox_aihub_to_yolo()` | 좌표 변환 (정규화) |
| `write_yolo_label()` | YOLO .txt 파일 작성 |
| `write_data_yaml()` | 설정 파일 생성 |
| `train_yolov8()` | 모델 학습 |
| `test_model()` | 모델 추론 |
| `build_event_metadata()` | JSON 결과 생성 |
