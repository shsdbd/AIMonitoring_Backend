# Step 10. 요구사항 추적성 매트릭스(RTM) 작성

## 1. RTM 작성 목적

요구사항 추적성 매트릭스(RTM, Requirements Traceability Matrix)는 상위 목표, 사용자 시나리오, 유스케이스, 기능 요구사항, 수용 기준이 서로 빠짐없이 연결되어 있는지 확인하기 위한 표다.

이 프로젝트에서는 특히 **관제사 시나리오가 실제 기능 요구사항과 검증 기준으로 이어지는지**를 점검한다.

## 8. Step 10 결론

요구사항 추적성 매트릭스 기준으로, 상위 목표와 관제사 시나리오는 기능 요구사항 및 수용 기준까지 연결되어 있다.

다만 다음 항목은 후속 협의 또는 MVP 범위 조정이 필요하다.

1. AI -> 백엔드 공식 요청 형식
2. bbox 좌표 기준과 프론트엔드 매핑 방식
3. 신규 이벤트 알림 방식
4. 관제사/AI 인증 방식
5. 처리 기록 기능의 MVP 포함 여부
